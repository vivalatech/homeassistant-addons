# Samsung Frame TV Art Changer

Send a new artwork to a Samsung Frame TV from Home Assistant. Sources include
Google Arts & Culture, Bing Wallpapers, and the Home Assistant media folder.

This proposed update adds color, museum, and art-style filters, persistent
duplicate prevention, and an atomic dashboard preview at
`/media/frame/latest.jpg`.

See [DOCS.md](DOCS.md) for configuration, filter helpers, and the complete
dashboard card.
